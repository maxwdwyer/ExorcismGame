Hello, the game files are zipped because there is too many sprites and sprite layers to upload it unzipped because github only lets me upload up to 100 files at a time.
I have put the scripts and objects folders in here because they fit, so if you just wanna look at the code and none of the rooms, sounds, sprites and stuff, you can do that.
I could not upload the executable because although the exe itself is only ~7.5 Mb, the data.win it needs to work is ~36 Mb, the best way to play the game would be to extract ExorcismSourceFiles.zip and open the project in game maker, then run it in there.

Because of how game maker files and stuff are, the code is very fragmented, and it can be a pain to look through so I inside ExorcismGameDocumentationKinda.pdf is some documentation saying where things are, what things do, and clarifying some weird variable names.
